# MovieAnchor

Static-first movie discovery and reference site for **movieanchor.com**.

## Deployment

Deploy the repository root directly to Cloudflare Pages.

- Framework preset: None
- Build command: leave empty
- Build output directory: /

## Current V1

- Homepage
- Browse index
- Client-side search
- Science Fiction genre landing page
- Three seed movie pages
- Movie schema markup
- robots.txt and sitemap.xml
- Custom 404 and favicon
